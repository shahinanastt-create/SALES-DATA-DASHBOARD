**Key Features**
* **Dynamic Slicers:** Filter dataset seamlessly by Date timeline, Region (East, West, North, South), and Product Item.
* **KPI Metrics:** Real-time metrics for total revenue and unit sales volume.
* **Multi-Tab Navigation:** Custom side menu for switching views between Dashboard, Products, Salesmen, and Project Details.
